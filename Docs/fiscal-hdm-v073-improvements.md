# Фискальная печать: план правок под HDM v0.7.3

Сверка Shop / Waiter / `desktop.newtax/Src/printtaxn.cpp` с `Docs/uc_hhpek_hdm_integration_manual_2025_v073_arm+.pdf`.
Коды оплаты уже совпадают: карта `1`, Telcell `10`, Idram `13`.

## 1. Деньги и скидка

- Цену и все денежные поля слать с максимум 2 знаками. Количество — максимум 3.
- После каждой скидки округлять строку до 2 знаков по правилу мануала: `0.005 → 0.01`, `0.004 → 0.00`.
- Процент на строку оставлять как `discount` + `discountType = 1`. Скидку на весь чек слать как `additionalDiscount` (`8` — процент, `16` — сумма), не прятать её в цену.
- Перед отправкой проверять: `paidAmount + paidAmountCard + prePaymentAmount` покрывает сумму строк. Иначе HDM отвечает `152`, `166` или `189`.
- `partialAmount` использовать, если часть суммы остаётся долгом. Банк и долг сейчас в чек не входят.

## 2. Безнал

- В `paidAmountCard` класть сумму только той системы, чей код уходит в `PaymentSystem`. Смешанные карта + Idram + Telcell одним полем с одним кодом не соответствуют протоколу.
- Для Idram и Telcell оставлять `useExtPOS: false` и код `13` / `10`.
- Для банковской карты передавать `rrn` (12 символов) и `terminalId` (8 символов), если терминал их вернул.

## 3. e-Mark

- Хранить код с разделителем GS (ASCII 29). В JSON экранировать его как `\u001d`, кавычку как `\"`, обратный слэш как `\\`.
- Не вырезать GS в Waiter до печати. Сейчас `PrintTaxN` умеет вернуть GS только для одной схемы, где серийный номер ровно 13 символов.
- Длина кода 29–110, символы ASCII 33–126 и 29. Иначе HDM отвечает `195`.
- Перед продажей маркированного товара вызывать функцию `16` (проверка одного e-Mark).

## 4. Возврат

- Сначала функция `10`: прочитать исходный чек и взять `rpid` и `eMarks` оттуда.
- Частичный возврат слать с `returnItemList`, суммами возврата и теми же e-Mark.
- Полный возврат без списка строк оставлять только когда возвращается весь чек.

## 5. Поля строки и покупатель

- Не слать пустой `adgCode` (ошибка `192`).
- Обрезать `productName` и `productCode` до 50 символов.
- Единицу измерения брать из товара. Сейчас всегда уходит `հատ`.
- `partnerTin` — 8 цифр или `null`. В Shop длина уже проверяется, в Waiter нет (ошибка `193`).
